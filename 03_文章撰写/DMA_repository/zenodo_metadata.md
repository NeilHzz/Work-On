# Suggested Zenodo Metadata

## Title

Processed source data and analysis code for OVAL glycan-state analyses of avian eggshell matrix chemistry and shell-breaking mechanics

## Upload Type

Dataset

## Description

This Zenodo record contains processed source data, derived model outputs, finite-element summary inputs, and analysis code used to evaluate and reproduce the numerical summaries, statistical analyses, and source-data tables reported in the associated manuscript and Supplementary Materials. The archive includes processed protein MS and glycan MS workbooks, orthology and GO/CAFE5 analysis files, Re-Glyco PDB ensembles, APBS/SASA-derived CSV files, finite-element force-summary workbooks, finite-element project entry files, shared geometry, and final Supplementary Tables S1 to S7.

This is not a vendor raw-data archive. Raw mass-spectrometry instrument files and complete proprietary Workbench/LS-DYNA solver cache directories are not included. The repository supports reproducibility from the processed-data and derived-output level.
