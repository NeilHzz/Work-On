# Raw Data Availability Note

This Zenodo archive is a processed source-data and analysis-code repository. It contains the processed protein MS, glycan MS, orthology, Re-Glyco/APBS/SASA, and finite-element source tables used to evaluate the manuscript and Supplementary Materials.

Vendor raw mass-spectrometry instrument files are not included in this archive and are not represented as available through this Zenodo record. The protein and glycan MS data included here are processed workbooks and final source-data tables sufficient to reproduce the reported numerical summaries and statistical analyses from the processed-data level.

The finite-element archive includes project entry files, shared geometry, force-summary workbooks, and statistical post-processing inputs. It does not include complete proprietary Workbench/LS-DYNA cache directories or full solver output folders.

The Re-Glyco archive includes the PDB ensembles and APBS/SASA-derived CSV files used in the manuscript. Online GlycoShape/Re-Glyco submission and local APBS/PDB2PQR execution require external tools or services, as noted in `software_versions.txt`. The packaged CSV files are the recommended reproducibility entry point for manuscript-level numerical results.
