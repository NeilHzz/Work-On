━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SECTION I — VOICE & SUBJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Use first-person active voice as the default: "We found / observed / identified /
  examined / annotated / confirmed."
• Reserve passive voice ONLY for: (a) Methods steps without an agent, (b) sentences
  where the object must be foregrounded, (c) literature-review sentences.
• NEVER use "Fig. X shows that..." or "It can be seen in Fig. X that..." — figures
  are never subjects. Always write the finding first, then append the figure as a
  parenthetical: "...(Fig. 3)."

SECTION II — SENTENCE ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Default sentence type: compound-complex, ~35–55 words. Use short sentences
  (<20 words) only for paragraph-opening topic sentences or closing summary
  statements, to create deliberate rhythmic contrast.
• Front adverbial or participial phrases to signal logical sequence:
    "By targeting..., we provide..."
    "While X conventionally assumes..., our research demonstrates..."
• Use parallel tricolon for listing, with an expanded final element:
    "...to examine past ecologies, biodiversity, avian distribution and cultures."
• Compress attributive information into noun phrases; avoid relative clauses
  when a prepositional or participial phrase suffices.

SECTION III — TENSE LOGIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Simple past  → all actions performed in this study ("We found", "We observed").
• Simple present → established facts, field consensus, interpretive statements
  ("proteins describe divergences", "collagen is recovered from bone").
• Present perfect → prior work invoked for context ("have been identified",
  "has been applied").
• Never mix tenses within a single logical unit.

SECTION IV — EPISTEMIC MODALITY (HEDGING)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Use a three-tier hedging system:
  HIGH confidence  → "demonstrates", "confirms", "shows", "highlights"
  MEDIUM confidence → "suggests", "indicates", "is consistent with"
  LOW confidence   → "may", "likely", "potentially", "could reflect"
Mark unexpected findings explicitly with: "unexpectedly", "especially surprising",
"strikingly", "particularly". This signals novelty and raises reader engagement.
When challenging field assumptions, soften confrontation with conditionals:
  "If these patterns are confirmed..., it could ultimately mean that..."
  "...cannot be so easily reconstructed..." (double-negation assertion)

SECTION V — PARAGRAPH STRUCTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Every Results paragraph follows: Topic sentence → Evidence (data + figure) →
One-sentence functional interpretation.
Every Discussion paragraph follows: Confirm prior consensus → Extend with this
study's finding → Qualify / acknowledge limitations → Implication or recommendation.

Transition vocabulary:
  Additive    : "Furthermore", "Moreover", "Additionally"
  Contrastive : "In contrast", "However", "While", "Although", "Meanwhile"
  Causal      : "This indicates that", "This demonstrates that", "Therefore"
  Sequential  : "We next", "We then", "To this end", "To examine"
  Summative   : "Taken together", "Overall", "Together"

NEVER use "Firstly / Secondly / Thirdly" enumeration.
Replace with contrastive-connective prose:
  Instead of "First, X. Second, Y. Third, Z." →
  "X. In contrast, Y. The largest/most notable case was Z, which..."

SECTION VI — QUANTITATIVE DATA REPORTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Embed numbers as parenthetical specifications, never as standalone sentences:
    "...most commonly in BPIfoldB4 (13 of 27 species)... and seldom in Albumin
    (4 of 27 speciesmi)."
• Use "X of Y" ratio format rather than bare percentages for sample-level data.
• For comparative statements: "highest in X (value) and lowest in Y (value),
  respectively."
• All statistical values, bootstrap scores, p-values, and n follow the result
  clause directly in parentheses: "(bootstrap >90)", "(p < 0.001)", "(n = 8)".
• Define ± notation at first use: "mean ± s.d." Declare test directionality:
  "two-tailed". Expand all abbreviations at first use.

PERCENTAGE / COMPOSITION FORMATTING
• Each percentage value MUST appear in parentheses immediately following its
  category name: "[type] (X%)" — NEVER write bare "type X%" without parentheses.
• For multi-component compositions, use a connecting phrase, not a bare list:
    CORRECT: "dominated by High-Mannose glycans (60.7%), with Neutral
              Complex/Hybrid (30.9%) and Fucosylated (8.4%) fractions."
    CORRECT: "was the most compositionally diverse, with Sialylated Complex/
              Hybrid (49.4%), Neutral Complex/Hybrid (38.1%), and High-Mannose
              (12.3%)."
    CORRECT: "[type] predominated (X%) with minor [type] (Y%) and [type]
              (Z%) fractions."
    WRONG:   "...with Neutral Complex/Hybrid comprising 30.9% and
              Fucosylated 8.4%."
    WRONG:   "Sialylated 49.4%, Neutral 38.1%, High-Mannose 12.3%."
• NEVER write "comprising X% and [name] Y%" — the percentage always follows
  the name in parentheses, not the other way around.
• Single-component cases: "[entity] carried exclusively [type] (100%)." ← correct.

SECTION VII — INLINE METHOD DISCLOSURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Results/Discussion, describe methods only via these five patterns — never
as a standalone method paragraph:

  1. PURPOSE-ACTION:
     "To examine X, we performed Y (Fig. Z)."
     "In order to assess X, we analysed Y."

  2. FINDING-TRIGGERED VERIFICATION:
     "Given the unexpected finding of X, we tested Y by Z."
     "Because X was observed, we examined whether Y."

  3. PARENTHETICAL TOOL CITATION:
     "...using GATK v.4.5.0.0 following best practice guidelines^{ref}."
     Tools, versions, parameters → parentheses or Supplementary only.

  4. RESULT SENTENCE WITH EMBEDDED METHOD:
     "The concatenated tree, covering 5553 amino acid positions, had..."
     (method compressed into a participial/prepositional phrase)

  5. BACK-REFERENCE SHORTHAND:
     "Using the reads previously mapped to the target gene, we performed..."
     Never re-explain a method already described; use "previously / as above /
     using dataset 2."

Max length of any inline method clause in Results: ~20 words.
Technical details exceeding this limit → Methods section or Supplementary Note.

SECTION VIII — RESULTS vs. DISCUSSION BOUNDARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RESULTS contains ONLY:
  ✓ First-order data facts readable directly from figures/tables
  ✓ Quantitative comparisons between groups
  ✓ Exclusion of technical artefacts (negative results)
  ✓ One-sentence functional mapping: data feature <-> known biological trait,
    using "consistent with / reflecting" — no literature citation required

DISCUSSION contains ONLY:
  ✓ Comparison with published literature (always cite)
  ✓ Mechanistic explanation of why a pattern occurred
  ✓ Critique of field assumptions ("we argue that...")
  ✓ Limitations and potential error sources
  ✓ Methodological recommendations (bullet-point norms if needed)
  ✓ Broadening generalisation: extend findings beyond the study system

Diagnostic test: if a sentence requires a superscript citation to be valid,
it belongs in Discussion, not Results.

SECTION XI — INTRODUCTION STRUCTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Based on Codlin et al. 2025 (Nat. Commun.) and Ba et al. 2022 (Sci. Adv.).

MACROSTRUCTURE — strict funnel in 4 paragraphs:

  §1  BACKGROUND VALUE (~100–150 words)
      Open with one short (< 20 word) declarative sentence establishing the
      biological system's importance. Expand into 2–3 compound-complex sentences
      covering: (a) what is known about the system, (b) why it matters
      evolutionarily or ecologically. Do NOT cite specific papers here — state
      established consensus only (present tense throughout).
      Pattern: "[System] is/provides/serves as [value]. [Expanding context].
               [Connecting the system to the research focus]."

  §2  PRIOR WORK & ITS LIMITS (~150–200 words)
      Survey existing approaches in a logically ordered sequence, each ending
      with a "However / yet / but" pivot clause that marks what is still missing.
      Use present-perfect tense for prior work ("have been identified / has been
      applied"). For each approach or body of work, follow the template:
        "[Approach X] has [achieved Y] — however, [limitation Z] remains."
      Two or three such pivots are typical. Do NOT introduce your own findings.
      Citations go here (not in §1 or §3).

  §3  CORE GAP (~50–80 words — SHORT BY DESIGN)
      State the single most important missing piece of knowledge in 1–2 sentences.
      Use present tense. Explicitly name what is unknown or uncharacterised.
      No citations, no methods. Short length is intentional — creates rhythmic
      contrast before the longer §4 and signals to the reader that the gap is
      sharp and tractable.
      Template: "Whether [X] is [Y] [qualifier] remains [unknown / an open
                question / uncharacterised]. Prior research has examined [A],
                [B], and [C] largely [scope], leaving [key linkage] uncharacterised
                in any integrated framework."

  §4  THIS STUDY (~100–120 words)
      Open with "Here, we..." followed by a participial phrase listing the
      methods/approaches, then the species/system with brief ecological rationale
      (1 phrase, not a full sentence). Close with a preview of the main findings
      using a "we demonstrate / we show / we reveal" verb.
      NEVER write "In this study, the purpose was to..." or "The aim of this
      paper is...". Use active declarative voice ("Here, we address / examine /
      demonstrate").
      Template: "Here, we [integrated approach list] in [species/system] —
                representing [brief ecological rationale] — to [goal].
                By [traversing / combining / linking] from [level A] through
                [level B] to [level C], we demonstrate that [core finding]."

TENSE MAP FOR INTRODUCTION:
  §1  Present simple (consensus facts)
  §2  Present perfect (prior work) + present simple (field-state sentences)
  §3  Present simple (gap statement)
  §4  Present simple (what this study does) + past simple only for any
      specific quantitative outcome already established

PROHIBITED IN INTRODUCTION:
  ✗  No figure references (no "Fig. X" or "see Results")
  ✗  No p-values, n counts, or statistical test names
  ✗  No numbered lists or bullet points
  ✗  No "Firstly / Secondly / Thirdly" enumeration
  ✗  No "In this study, the aim / purpose / objective was..."
  ✗  No standalone method sentences (methods in §4 only as part of a
     participial phrase embedded in the "Here, we..." sentence)
  ✗  Do not re-state the Abstract verbatim — §4 previews findings, does
     not reproduce the abstract

TRANSITION VOCABULARY SPECIFIC TO INTRODUCTION:
  Gap pivot     : "however", "yet", "while X has been..., whether Y remains..."
  Gap naming    : "remains unknown", "has not been systematically examined",
                  "has not been characterised in any integrated framework",
                  "leaving [X] uncharacterised"
  Study opener  : "Here, we", "To address this gap, we", "We leverage [X] to"
  Contribution  : "we demonstrate that", "we show that", "we reveal that",
                  "we provide [the first / a systematic / a cross-species]..."
  Rationale link: "representing [X] and [Y] ecological guilds",
                  "spanning contrasting [developmental strategy / ecology]"

SECTION XII — METHODS WRITING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Based on Ba et al. 2022 (Sci. Adv.), Codlin et al. 2025 (Nat. Commun.),
and Nature Communications submission guide (2019).

JOURNAL REQUIREMENTS (from ncomms-submission-guide):
• Methods appears in ALL online original research articles.
• Target length: ≤3,000 words (may exceed if necessary for replication).
• Must contain ALL elements needed for interpretation AND independent replication.
• A dedicated Statistics subsection is REQUIRED: state which tests were used
  and whether they were one- or two-tailed.
• Report EXACT n values (not ranges); define replicates explicitly.
• Provide exact p values for both significant AND non-significant results.
• For ANOVAs: provide F values and degrees of freedom.
• For t-tests: provide t-values and degrees of freedom.
• Define all error bars in figures (error bar type must appear in Methods or
  figure legends, not assumed).

MACROSTRUCTURE — subheadings required:
• Use bold subheadings for every distinct method subsection — never write
  Methods as one continuous block.
• Order of subsections follows the logical flow of the experiment, not
  alphabetical order: typically Sample → Processing → Instrument → Analysis →
  Statistics.
• Ba 2022 pattern: "Skin fibroblast cell culture" → "RNA isolation" →
  "Protein extraction" → "Phosphopeptide enrichment" → "LC separation" →
  "DIA-MS measurements" → "Database search" → "Data analysis and statistics"
• Codlin 2025 pattern: "Sequence annotation" → "Curation" → "Assessment of
  accuracy" → "Variant calling" → "Pairwise distance analysis" → "Phylogenetics"

VOICE & TENSE:
• Use passive voice throughout Methods — this is the ONLY section where
  passive is the default:
    "Cells were washed with PBS twice."
    "Protein concentrations were determined by Bradford assay."
    "Sequences were aligned using MAFFT v.7.453."
• Simple past for all completed procedures.
• Present simple ONLY for general truths or ongoing definitions:
    "A MapQ score of ≤3 is considered evidence of multi-mapping."

TOOL & VERSION CITATION:
• Always specify software name + version number at first use:
    "Spectronaut v14", "GATK v.4.5.0.0", "MAFFT v.7.453",
    "Geneious Prime 2024.0", "VCFtools (0.1.16)", "R v.4.4.2"
• Commercial reagent: include manufacturer and catalogue number in parentheses:
    "Fe-NTA kit (Thermo Fisher Scientific, A32992)"
    "trypsin (Promega)"
• Database releases: cite version/release date:
    "Ensembl release 100 (May 2020)"

PARAMETER REPORTING:
• Embed all numerical parameters in parentheses within the procedural sentence:
    "(30 min in 0.25% trypsin buffer at 37°C)"
    "(peptide and protein FDR < 1%)"
    "(MQ < 40.0; DP < 10; maf < 0.05)"
• Thresholds used as quality filters MUST be stated with their rationale
  or the reference that established them:
    "a MapQ score of ≤3 was considered evidence that a read matched to more
    than one area of the genome"
    "variants longer than three consecutive SAPs were removed because it was
    considered unlikely that such extensive variation would occur in closely
    related species"

BACK-REFERENCES & CROSS-REFERENCES:
• Never re-describe a method already presented; use explicit back-references:
    "as previously described (ref)"
    "using dataset 1 (see Sequence annotation above)"
    "using the reads previously mapped to the target gene"
• Cross-reference supplementary material for details exceeding Methods scope:
    "see Supplementary Note 4 for further details"
    "All modifications were recorded and are available in the associated
    repository"

MANUAL CURATION & DECISION CRITERIA:
• When automated pipelines are supplemented by manual steps, state the
  decision logic explicitly (Codlin 2025 standard):
    "A judgement was made whether to include a SAP or recode the variant as
    missing based on comparison to other species, the length and type of
    variation, and its proximity to the end of an exon."
  Do NOT write "variants were manually checked" without stating the criteria.

STATISTICS SUBSECTION (mandatory standalone heading):
• Must appear as the final subsection before Data Availability.
• Template structure:
    1. State software/language used: "Statistical analyses were performed in
       R v.X.X.X / Python v.X / GraphPad Prism vX."
    2. Enumerate each test by result type: "Group comparisons were made using
       [test]; correlation was assessed by [test]."
    3. Declare directionality for every test: "all tests were two-tailed."
    4. State significance threshold: "p < 0.05 was considered significant."
    5. Define error metric: "Data are presented as mean ± s.d. unless stated."
    6. Define replicates: "n refers to biological replicates; technical
       replicates were averaged before analysis."

ETHICS & COMPLIANCE:
• If animal or human samples were used, state the approval number and
  approving committee in the relevant subsection (not a standalone section):
    "Sample preparation was approved by the Institutional Animal Care and
    Use Committee under protocol no. 2021-11483."

PROHIBITED IN METHODS:
  ✗  Do not begin any sentence with a result or interpretation — Methods
     contains procedures only, no findings
  ✗  Do not write "We found / We observed" in Methods — finding language
     belongs in Results
  ✗  Do not omit version numbers, catalogue numbers, or release dates
  ✗  Do not use vague quantifiers ("some samples", "a few replicates") —
     always give exact counts
  ✗  Do not embed long inline method blocks (>3 sentences) inside Results
     paragraphs — move them to Methods (see Section VII)
