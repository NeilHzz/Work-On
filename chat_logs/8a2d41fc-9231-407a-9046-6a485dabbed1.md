## 1. Ramachandran 角（φ/ψ 主链二面角）

**PyMOL 按 φ/ψ 着色：**
```python
from pymol import cmd, stored

cmd.load("protein.pdb", "prot")
cmd.bg_color("white")

# 用 DSSP 指派二级结构，按构象区域着色
cmd.dss("prot")                    # 计算二级结构

# 直接提取 phi/psi 并着色
stored.angles = {}
cmd.iterate_state(1, "prot and name CA",
    "stored.angles[resi] = (phi, psi)")

# 拉氏图配色方案：helix=红 sheet=黄 loop=灰
cmd.color("red",  "prot and ss h")   # α螺旋区
cmd.color("yellow","prot and ss s")  # β折叠区
cmd.color("gray", "prot and ss l+''")# loop/转角区
cmd.show("cartoon", "prot")
```

更完整的 Ramachandran 分析推荐配合 **PROCHECK** 或 **MolProbity** 输出，再用 PyMOL 高亮异常残基：
```python
# 高亮 outlier 残基（从 MolProbity 报告中读取列表）
outliers = [23, 67, 112]  # 替换为实际残基编号
for r in outliers:
    cmd.select(f"out_{r}", f"resi {r}")
    cmd.show("sticks", f"out_{r}")
    cmd.color("magenta", f"out_{r}")
```

## 2. 螺旋交叉角 / Helix Crossing Angle

对于同源三聚体（如您图中），可视化螺旋之间的夹角：
```python
# 用 PyMOL 内置 angle 测量两螺旋轴夹角
# 先获取各螺旋的起止 CA 原子
cmd.pseudoatom("ax1_start", pos=[x1,y1,z1])
cmd.pseudoatom("ax1_end",   pos=[x2,y2,z2])
cmd.pseudoatom("ax2_start", pos=[x3,y3,z3])
cmd.pseudoatom("ax2_end",   pos=[x4,y4,z4])

cmd.angle("helix_angle", "ax1_start", "ax1_end", "ax2_start")
```

或用 **HELANAL / INTERHLP** 自动计算所有螺旋轴，导出角度后映射回结构。

## 3. 回转半径 Rg（MD轨迹分析）

若用 MD 模拟数据，Rg 是标量，不是"角度"，通常用 **MDAnalysis** 计算并绘图：
```python
import MDAnalysis as mda
import matplotlib.pyplot as plt
import numpy as np

u = mda.Universe("topology.tpr", "trajectory.xtc")
protein = u.select_atoms("protein")

rg_values = []
for ts in u.trajectory:
    rg_values.append(protein.radius_of_gyration())

plt.plot(u.trajectory.time / 1000, rg_values)
plt.xlabel("Time (ns)")
plt.ylabel("Rg (Å)")
plt.savefig("Rg_plot.png", dpi=300)
```
