### 98. Assistant (2026-05-31 19:47:26 中国标准时间)

“同一组糖型集合” 指的是：

在同一个 orthogroup 里，多个蛋白不一定都只有 1 种糖型，但它们各自对应到的糖型列表是一样的。

这个判定逻辑就在 [02_可视化/Figure/MainFig2_cluster_glycotype_visualization.py](02_可视化/Figure/MainFig2_cluster_glycotype_visualization.py) 里。它先看每个蛋白对应的糖型集合，再比较这些集合彼此是否完全相同。

最容易理解的三种情况是：

1. Single glycan type
所有蛋白最后都只对应 1 种糖型，而且是同一种。
例子：
蛋白 A = {High Mannose}
蛋白 B = {High Mannose}
蛋白 C = {High Mannose}
这种情况整个 cluster 只有 1 类糖型，所以叫 single glycan type。

2. Same multi-type set
每个蛋白都对应多种糖型，但它们的集合完全一样。
例子：
蛋白 A = {High Mannose, Hybrid, Complex-Plain}
蛋白 B = {High Mannose, Hybrid, Complex-Plain}
蛋白 C = {High Mannose, Hybrid, Complex-Plain}
这里不是单一糖型，因为有 3 类糖型；但 A、B、C 的集合完全一致，所以叫 same multi-type set。

3. Mixed type sets
cluster 里不同蛋白的糖型集合不一样。
例子：
蛋白 A = {High Mannose, Hybrid}
蛋白 B = {High Mannose, Complex-Plain}
蛋白 C = {High Mannose, Hybrid, Complex-Plain}
虽然这 3 个蛋白有重叠，但各自的集合不同，所以是 mixed type sets。

所以“同一组糖型集合”的核心不是“有几种糖型”，而是：

同一个 orthogroup 里的每个蛋白，是否共享完全相同的糖型组合。

你可以把它理解成：

1. Single glycan type：大家都只有同一种糖型。
2. Same multi-type set：大家都有同一套多糖型组合。
3. Mixed type sets：大家的糖型组合不完全一样。

严格说，没有“composition-aware 和 Jensen-Shannon / Bray-Curtis”这种并列差距，因为 composition-aware 不是一个具体指标，而是一类思路。

它的意思是：比较两个样本时，要看完整的组成向量本身，比如 7 类 glycan type 各自占多少，而不是只把它压缩成一个数，比如 richness 或 Shannon。Jensen-Shannon 和 Bray-Curtis 都属于 composition-aware 的具体实现。

你这张图里，真正的区别是这两层：

1. richness / Shannon
它们回答的是“多不多”“均不均匀”。
它们不回答“到底是哪一类 glycan 在变”。

2. composition-aware distance
它回答的是“组成结构变了多少”。
也就是 High Mannose、Complex-Fucosylated、Complex-Sialylated 这些类别之间的比例重排有多大。

所以从信息含量上说，composition-aware 比 richness / Shannon 更贴近你现在这张图的核心问题，因为你要讲的是跨物种 glycan landscape 的结构差异，而不只是多样性大小。

Jensen-Shannon 和 Bray-Curtis 的差别主要在这里：

1. Jensen-Shannon
它是信息论意义上的分布差异。
先把组成标准化成概率分布，再比较两个分布的信息偏离程度。
更适合“比例组成”这种问题。

它的特点是：
1. 对相对比例的变化更敏感。
2. 天然适合和你 C 图的百分比堆叠条形图对应。
3. 更像在问“两个 glycan composition profile 的分布形状差多远”。
4. 不会被总量大小直接带偏，前提是你输入的是归一化比例。

2. Bray-Curtis
它本质上是丰度差异指标，生态学里特别常见。
如果输入相对丰度，它也可以做 composition-aware 比较；如果输入原始计数，它会同时受到丰度规模影响。

它的特点是：
1. 直观，容易解释成“组成不相似度”。
2. 对高丰度类别的差异比较敏感。
3. 在群落生态、代谢组、微生物组里特别常见。
4. 如果你不先归一化，它会把 coverage 差异也带进去。

缺点是门槛高，不够主流，很多读者不会第一眼读。

6. Mosaic / Marimekko
能同时表达总量和组成。
优点是信息密度高。
缺点是对你这张主图来说太“统计图表化”，不够论文主图友好。
